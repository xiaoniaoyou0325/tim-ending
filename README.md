# tim-ending

把影视飓风 Tim 在视频结尾说的“涩话”，整理成一个可以反复调用的写作 Skill。

## Tim 式“涩话”结尾

一篇文章写完，想在最后多留一点东西，就可以把正文交给它，让它帮你写一段 Tim 式的“涩话”结尾。

这里说的“涩话”，是那种从眼前的一件小事讲起，慢慢讲到人与人、人与时间的关系，最后又落回生活的收尾。看完以后，让人愿意停一会儿，再想想自己。

这份 Skill 根据 Tim 的公开文案、原片信息和创作者访谈，提炼了其中的叙事方法。使用时，它会先读你的正文，找到最值得回扣的真实细节，再把情绪接起来，保留你自己的说话习惯。

这份技能包含写作指令、研究来源、原创样例、反例和自检标准。它不要求每篇文章都抒情，也不把普通教程强行写成人生感言。

| 技能 | 适用任务 | 入口 |
| --- | --- | --- |
| `tim-ending` | 结尾升华、涩话、骚话、公众号与口播收尾、已有结尾改写 | [SKILL.md](skills/tim-ending/SKILL.md) |

## 怎样使用

1. 点击仓库页面的 **Code → Download ZIP**，解压。
2. 找到 `skills/tim-ending`，保留整个文件夹。
3. 按你使用的 AI 工具支持的方式安装这个 Skill。也可以让支持读取本地文件的助手读取 `SKILL.md` 及其引用。
4. 提供本次文章正文，或者最后几段与要回扣的真实故事。

调用示例：

> 请使用 $tim-ending，给下面这篇文章写一个有余味的结尾。保留我的口吻，从正文里的真实细节出发，先给一版。

可以继续补充“收得更轻一点”“情绪可以再往上走一点”“保留最后这句互动”等要求。

技能提供方法，每篇文章仍需要自己的素材。缺少人物故事的操作教程，可以停在一个清楚的判断或下一步动作。
