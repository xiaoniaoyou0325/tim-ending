# 写法与检查

## 先判断这篇该怎样结束

这种收尾的价值，是让前文的经历多留一会儿。它不要求每次都高声抒情。实用评测可以停在一个清楚的选择，旅行可以停在路边的人，技术项目可以停在那个人为什么需要它。

动笔时心里有三件事就够了：前文留下了什么，作者因此想到什么，读者最后带走什么。它们可以写成两段，也可以写成六段，不要求固定顺序和段数。

用户要求有感触的收尾时，还要写出作者为什么在意这件事。只是复述素材、重复工具功能或追加操作建议，还没有完成这个任务。保留细节以后，说出它让作者重新看见了什么。这可以是基于材料的个人理解，不必每句感想都有报道出处；仍不能把联想伪装成亲历或当事人的心理。

## 从这次 Tim 研究中提取的方法

### 具体事物会让感慨有来处

房间扫描、机场的飞机、观众留下的信息、早餐和休息，承担着各自作品的情绪。物件和动作已经在前文被读者看见，最后再出现时，它们的分量会发生变化。

新文章也要找自己的东西。它可能是一首歌下面的一条留言，不需要模仿房间、飞机或卫星。

### 可以把视线放远，也可以把期待收小

记录和时间的题材，适合从眼前的一件事想到以后。压力和休息的题材，可能更适合从很远的目标收回一顿饭或几分钟空闲。方向由材料决定，不能每次都用“渺小的人与浩瀚宇宙”。

### 任务完成之后，还有一个人的问题

项目已经做出来，故事未必已经结束。留下房间是为了记住谁？把信息送向远处，是谁希望自己的话被看见？一个能力更强的工具，让哪个原本做不到的人有了机会？

只选正文确实能回答的一个问题。不要结尾连问五个宏大问题，随后用一句人生哲理糊过去。

### 给读者留位置

可以说“我想到”“我觉得”，也可以直接停在场景里。个人感受有边界，读者可以有自己的理解。不要把“有人感动”扩写为“全世界终于彼此理解”，也不要把一首歌写成已经消除了悲伤。

### 文字需要自己完成转场

视频还有画面、音乐和停顿。公众号没有同样的时间控制，不能只抄视频尾句，指望读者自动被打动。用一两句把真实细节和感受接起来；关系已经清楚时，及时停笔。

## 在不同材料上作选择

| 前文真正提供的材料 | 可走的方向 | 容易写过头的地方 |
| --- | --- | --- |
| 陌生听众谈到相似的思念 | 距离很远的人，共享某种感受 | 断言他们互相理解、获得治愈 |
| 保存照片、声音或房间 | 记住一个具体的人与当时的自己 | 把记录说成战胜遗忘或实现永生 |
| 一次共同完成的困难项目 | 参与的人、付出的过程、共同记得的事 | 只颂扬技术奇迹，删掉人 |
| 太远的目标和疲惫 | 缩小期待，落到眼下能做的事 | 让陌生作者命令读者放下焦虑 |
| 普通工具与操作体验 | 一个清楚判断或下一次实际使用 | 硬接生命意义、人类文明 |

这些是选择依据，不是句式模板。

## 三个实用的改稿动作

发现“连接世界”“改变生活”“技术有了温度”时，先问正文里到底是谁、在哪一步、发生了什么。把能回答的部分写出来，泛词通常就能删掉。

发现“我震撼了”“我久久不能平静”时，检查用户是否真的提供了这个反应。没有就删除反应，保留引起思考的材料。

发现连续三段都在说同一个道理时，保留最具体的一段。结尾的余味通常来自克制后的空间，不来自再解释一次。

## 轻量质量门槛

内部用以下五项各评 0–2 分即可，不向用户展示自评分。

- 贴文：与正文的具体材料是否有不可替换的联系。
- 过渡：从事实走向感受是否读得顺。
- 落点：能否看见具体的人、关系、小事、动作或清楚的选择；纯操作题材不要求人物与抒情。
- 分寸：是否尊重材料边界与用户口吻。
- 停笔：是否在合适的位置结束，并接得上指定互动句。

任一项为 0 就修对应问题。8 分可作为交稿参考，不把分数当成质量证明，也不为了满分增加段落。
